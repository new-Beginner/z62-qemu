# r103：完成输入到有限统计的 C 级数据桥

属性`z62-readout-statistics`默认off，要求`z62-input-readout`与`functional-finite-stats`。r102、r98及默认r75界面／r69内核保持。C1.70原字节／AF没有修改；本模型不是Nikon测光／PDAF或物理CMOS等价实现。

## 数据资格

- 使用原厂提交的correction0、2020×136→2020×136、enable11h，以及实际启用的有限统计unit4。
- 输入资格同时核对现有30×12、61槽、bank0／1、pitch12000h或0的有限描述符。不把unit0启动当作前置统计的资格。
- 只有完整消费的显式Z62M／linear16输入可进入统计缓存。缺帧时拒绝，不能回用旧CW图像或增加旧RAW计数。
- 完成缓存独立于下一份输入lease；正在输出的768B统计平面及epoch／publication／frame／time再独立冻结，后续输入只更新latest。
- 一个batch仍是同一保留图像的61次统计采样，不是61个新RAW采集。已有61槽资格、全批内存预检、真实DMA、IRQ／W1C和取消机制保持。
- C数学为每像素`linear16 >> 4`后，对30×12整数分区求四舍五入均值；LE-u16、row64，每行末尾4字节0。它没有真实标定、噪声或Nikon算法含义。
- 缺源拒绝后，真正完成的新输入只使设备重新尝试准备；完成状态仍须由实际统计DMA产生。停止／重新启用要求新输入，reset清除缓存、批次和待完成任务。

## 本次验证

| 范围 | 实际结果 | 限制 |
|---|---|---|
| 新native | 2进程exit0，两批122次DMA／93,696字节逐次读回并由独立积分图重算一致 | 合成ARM循环，无Nikon固件 |
| 来源／所有权负例 | 旧CW保留图像不作fallback；pending lease不覆盖completed cache；owned batch不变、下次选latest；停止需新输入、取消、越界和reset通过 | 不是全部并发时序穷尽 |
| 旧路径 | 同r103的r102读出及r98保留CW有限统计原生回归通过 | 默认off兼容，不提升默认入口 |
| 16秒原厂断点窗口 | 两个800h等待均为kernel0／BOOL1，见到真实原厂OR/store；状态[]、CW308、grid169 | 有断点扰动；该轮未捕获scalar，缺口保留 |
| 24秒无GDB窗口 | 两批122采样；两份原厂scalar共1,536字节独立重算一致；CW541、grid322、状态[] | 两次短QMP暂停取数，不称物理无扰动时序 |
| 原厂LCD | Error消失、拍摄OSD恢复，背景绿色、preview0 | 原厂取景图像、完整摄影／AF和刷机安全仍未完成 |

本实验配置下，先前已定位的停止等待失败与3Fh报错已自然消除；这不覆盖全部机身模式、原厂算法、NOR／个体标定或更新路径。

下一阶段核对CW真实输出到预览的来源交付。当前生成源的`preview_source_notify`仍从旧RAW stream或独立paired输入取得资格；CW实际RAW不等于这些来源已经接通。不得增加旧RAW计数，也不能把一帧复制为四帧。应按真实bank／ring和源身份收集完整cohort，使用冻结transfer区分编码域／线性域，再验证预览提交、像素和原厂LCD消费。
