# r102：2020×136 的 C 级内联读出

默认关闭属性`z62-input-readout`，依赖CW控制模型。它消费**显式提供的MAIN／linear16软件视图**，不是物理CMOS、完整SDES／EX协议、RAW DMA或传感器编码。r98和默认r75／r69保持。当前原厂Error未修复。

## 输入资格和所有权

- 已提交的correction=0，几何精确为2020×136→2020×136，enable=11h；correction／几何必须有原始提交资格。
- 当前CW控制模型中unit0释放、允许且运行，相关后端0Ch／200h不运行。未知布局、缺配置、停止或其它组合拒绝。
- QOM `input-readout-file`只接受有界普通ASCII路径文件，使用既有Z62M包的CRC、角色、时间／帧号、epoch／publication、零padding与缓存所有权校验；宽2020、高136，stride≤4096。
- 接受后缓存按值拥有，不受宿主mailbox替换影响。1ms是明确的C级传输延迟假设，不是硅片时序。暂停的VM不处理，停止／配置代次变化／reset取消未完成工作。
- 完整读取136行有效linear16像素，保留实际输入身份，计算LE-u16总和与FNV1a64；每帧有效549,440字节。padding不算有效像素。
- 全部行处理后才脉冲`input-readout-complete`，接入既有functional sensor completion输入；其mode／mask／W1C资格保持。寄存器写入、缺帧和被拒／取消的任务不能产生完成。

本模型不写客体软件事件／ready／返回值，不增加`raw_accepted`，不声称产生新的客体RAW DMA。sensor旧属性`raw-source-events`记录实际收到的数据完成边沿，不应仅凭名称把内联视图说成packed RAW采集。

## 原生和原厂通过范围

| 检查 | 实际结果 | 边界 |
|---|---|---|
| 新native | 2个进程exit0；549,440字节有效像素的sum／FNV独立重算一致 | 合成ARM循环，没有运行Nikon固件 |
| 原生负例 | 默认off、缺源／配置、暂停、坏CRC／尺寸／epoch／旧帧、mailbox替换、取消／重启／reset、mask／W1C均通过 | 不是全部并发和物理时序穷尽 |
| 新内核旧CW回归 | 6帧、9,138,504样本核对，全部进程exit0 | 原生设备级验证 |
| 新内核旧retained finite回归 | 两输入、122次采样DMA、批次身份冻结通过 | 仍是保留图像采样，不是122个新RAW |
| 原厂16.001121500秒 | 31个CW输入、288个内联读出；319个源包可逐字节重构；实际内联有效字节158,238,720 | 原厂第一次失败前尚未开放本模型的unit0资格 |

## 当前未覆盖的前置阶段

r101直接证实：C18A7634h／800h等待在有限统计结束后失败，mode2及消费者mask已经就绪，但sensor数据源计数0、初始化完成只有1。r102保持unit0控制资格，因此数据只在失败返回后进入；不能放宽启动检查或补IRQ来迁就等待。

下一步区分有限统计unit4阶段的真正输入与随后unit0内联阶段，恢复前者的来源、描述符和实际消费者。可研究显式C输入到30×12统计的桥，但必须让同一输入实际生成统计DMA、冻结批次身份，并验证原厂提交／消费；不把retained CW图像或只算checksum当作前置统计的数据来源已经补齐。

构建／验证见[r101–r102报告](../../docs/history/2026-11-04_实施-Z62原始停止等待与内联读出r101-r102-report.md)。完整相机、AF、模式往返、全局快照与刷机安全仍未验收。启用CW时仍阻止完整迁移；内联缓存和timer在reset／unrealize清除。
