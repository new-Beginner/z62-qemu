# r88 RAW transfer 合同

2026-11-04，C级模型。该接口只定义本项目数值链路的像素域；没有QEMU设备、DMA或IRQ，没有恢复原厂ISP或验证硅片等价。

## 冻结描述

`Z62T` v1固定532字节，小端。头部依次为magic `Z62T`、u32 version=1、u32 bits、u32 codec；随后256个u16 LUT项；最后u32 IEEE CRC32覆盖前528字节。codec0为`shift`，codec1为`lookup8-high-byte`。bits仅12／14／16；shift描述的LUT必须全零，LUT8描述必须有256个严格递增且不超位宽的值。

Python对象是frozen dataclass，构造时把外部曲线复制为tuple；C快照按值存入256项数组，工作时不再保存可变MMIO或外部LUT指针。载荷回执绑定描述的SHA256。CRC只是意外损坏检查，不是认证，也不证明描述来自原厂有效commit。

描述尚未含真实硬件的bank/ring或run身份；QEMU接入时必须把它随已确认配置、输入帧、任务代次一起冻结，不能从后来变化的寄存器猜测旧帧像素域。

## 解码返回什么

| 编码 | 原输入范围 | 代表值 | 信息损失 |
|---|---|---|---|
| shift16 | `[code,code]` | code | 无 |
| shift14 | `[code×4,code×4+3]` | 下界+2 | 2位 |
| shift12 | `[code×16,code×16+15]` | 下界+8 | 4位 |
| LUT8 | 唯一匹配LUT索引i对应`[i×256,i×256+255]` | 下界+128 | 8位 |

LUT8输出严格属于256个已声明编码；未知值会被拒绝。这里的“解码”是量化区间重建，不能恢复原始低位，也不是原厂物理反变换。代表值使用上中点；最大绝对误差界为quantum/2。调用者可同时取得上下界，不能把代表值误记为原始样本。

## 整帧行为

C解码器将packed12／14／16逐行读取为线性16 LE。输入／输出stride独立，行填充保持原值。尺寸≤4096、≤4 Mi samples、跨度≤64 MiB；不接受重叠地址、短缓冲、错误描述或半字节行。

先冻结描述并校验几何／范围，再扫描整帧编码；全部可解码后才写输出。因此末像素编码非法也不会留下部分输出。输入需由序列化所有者保持只读，和r87读占用的生命周期要求相同；不支持无保护的并发写入。

## 已验证范围

- 8项专项包含Python／C描述互操作、外部LUT修改隔离、坏描述保持、末像素非法时零输出写入、地址重叠／短缓冲／stride拒绝。
- 四种配方各遍历全部65,536种输入：shift12／14／16和LUT8。仅shift16声称无损，其余按独立量化区间参考验证。
- 复用r87两帧MAIN、r86几何／LUT：`MAIN → 原C核心打包 → 冻结transfer解码 → 线性16`。3,046,168样本零差异，实际最大误差50／65535；这个50仅适用于该测试图，通用界仍为128。输出padding保持，正向packed字节与r87完全一致。

原始数值case在`analysis/z62-raw-transfer-r88/scene-1`，含10份源码归档；正式范围和全量回归见r88报告。旧r69设备、EXE和原厂状态未修改，后续还需确认Z62的实际commit、bank/ring、任务代次、取消与DMA／IRQ时序，并接入下游ISP。
