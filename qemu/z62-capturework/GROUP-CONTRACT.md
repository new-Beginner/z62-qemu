# r93 unit20/capture-group 有限参考处理器

此实现默认关闭，属性为 `nikon-z72-input-config.z62-capture-group`，要求同时启用 CW MAIN 路线。它是 C 级 LUT/FIR/区域统计参考运算和有限传输模型，不是原厂 AF、PDAF 或硅片算法。默认相机入口仍为 r75 界面／r69 内核。

## 已核对的 Z62 控制与数据路径

- 固定 C1.70 指令把 unit mask20h 注册到回调1023926Eh；回调读事件载荷 byte+0Ch bit0，并在102392B2h发布原厂软件事件 mask01000000h。设备只提供输入事件96，软件对象由原厂代码写。
- 原厂通过共享100h/104h提交 mask10h，通过00h/04h、10h/14h、08h/0Ch分别执行 reset、enable、run。配置快照独立于 CW 缩小／打包配方。
- 143个已观察必需配置字位于2006B800h至2006BD80h的有限子集。可选 B984h未在原厂窗口写入；本 C 模型用冷零约定，若实际写入非零则拒绝该未实现模式。配置／提交／单纯运行均不产生数据完成。

任务捕获已经过 CRC／角色／几何／虚拟时间验证的 MAIN linear16、冻结的 group 配置、bank、cursor及代次。当前实现与 CW 共享单个私有数值 worker，最短虚拟延迟沿用1ms；它不是独立硬件并行或真实芯片处理时间模型。CW之外的独立 MAIN acquisition／TG cursor 协议仍缺。

## 声明的数值模型

参考 [nightglasses/z7ii-qemu](https://github.com/nightglasses/z7ii-qemu) 固定提交 `0e53ea5a6d4f3fc635d63c195a92e943370ac5e9` 的 capturegroup 线格式、字段分类及有限参考算子，保留 GPL-2.0-or-later 与原作者署名。Z62控制、几何和实际配置另外核对，没有照搬 Z72 RAM/PC 或资源偏移。

| 部分 | C级约定 |
|---|---|
| 65点曲线 | 间隔1024的分段线性插值、向下取整，再由linear16转12有效位；拒绝常量、非单调和越界曲线 |
| 三组8-tap FIR | 首系数signed8，其余signed7；水平位移-3…4、边界clamp、绝对卷积除以系数绝对值和；零模系数拒绝 |
| ROI／网格 | 非零矩形、域尺寸上限16384，网格上限9×9；输入坐标按floor/ceil映射，区域和缩放到声明域面积 |
| Primary40B | 明度和／面积／三响应、饱和12/23/29位前缀及显式均值／中心坐标 |
| Companion24B | 明度和／面积／三响应；末4B保留 |
| Grid32B | 每格明度和／面积／前两响应及同类前缀、均值／中心X |

输入保留RGGB样本，FIR没有Bayer解混或物理离焦校准。面积、响应、前缀及半字意义均为参考算子约定，不能拿它评价原厂相位估计或真实合焦率。实现读取实际配置，不注入默认曲线或系数。

## 所有权、DMA与完成

只处理选中的ROI族／网格族，未选中的ROI几何和目标不阻塞有效网格；共享几何／模式及cursor资格仍须满足。两bank分别保留地址集，ring至多8槽，初始cursor来自提交配置，每次成功处理前进一次。本版按实际处理完成推进cursor，不声称恢复了独立TG元数据时序。

全部活动族、bank及ring跨度须是当前引擎地址空间内完整可写RAM；验证同bank各族／槽的物理backing重叠，并拒绝与CW输入RAW环重叠。没有“任意地址都返回成功”，也没有额外的代码区保护假设：可写启动RAM仍属于可写RAM，非法地址负例必须使用真实无效跨度。

worker只计算私有数据；虚拟时钟回调重新检查代次／pending／RAM，读取发布时目标字节，合并已分类字段。Primary的+16/+1E/+26半字、Grid的+16/+1E半字、Companion的+14整字及记录外区域都保留。所有活动族实际DMA成功后才更新8字cursor/address结果、实际完成计数和事件96。结果只读，客体写入不替换它。

raw3 bit0独立pending，即使屏蔽也背压group；仅20068270h bit0的W1C解除，其他统计ACK不解除。group阻塞／拒绝不伪装成CW或连续统计完成，也不通过增加旧RAW计数产生来源。group停止、disable、reset及已改变的提交配置使旧代次失效；CW取消同时取消所共享的任务。未穷尽inflight取消的全部宿主交错。

## 当前验证与原厂缺口

原生7帧三类记录共18,528字节独立重算一致；三族、五槽轮转、bank1只启用grid、masked pending／W1C、未分类字节、只读结果、停止／重启、reset及五类拒绝通过，9个自有进程exit0。旧统计及701项宿主回归通过。

原厂8.006秒窗口明确写入65个零曲线字和24个零系数字，C模型拒绝13次、完成0次，没有发出group完成。CW／连续统计仍各13帧，预览0、LCD全黑。零值的来源尚未确认，不能据此宣称NOR已擦除、相机固件损坏或物理硬件必然拒绝。

r94/r95已更正旧字段标签：packed系数实参是C26A0884h+3Eh，即C26A08C2h；+58h的C26A08DCh是另一组配置，曲线指针槽仍为C26A0904h。已按Z62原字节、被动读取和诊断标签核对资源39从虚拟group17进入provider／寄存器的路径；独立C参考输入使原厂窗口产生13次group工作及CPU ACK，但预览仍为0。真实工厂参数未恢复，详见 [参数合同](GROUP-PARAMETERS.md)。
