# 运行时ADC外部输入合同 r21

这是冻结r18模型的增量，新增 `input-channel0` 至 `input-channel18` QOM属性。它们表示外部模拟电平的12-bit采样码；并非写入客体软件参数、状态或完成通知。

- 数值范围0..4095。负数、越界、布尔值和错误类型拒绝，拒绝不改变旧输入。
- 初始值沿用已有 `channelN` 启动属性，不新增自动电平或默认完成行为。
- `adc_write()`在转换开始时把channels[channel]锁存至bank.sample；本扩展仅改变channels，因此正在转换的结果保持原值，下一次转换才使用新值。
- 数据分辨率、对齐、EOC/overrun/IRQ、取消和completion开关全部沿用原设备逻辑，不补造成功。
- 复位保留外部电平，清理转换状态；既有channels迁移字段继续使用，没有新客体可写寄存器。整机迁移未验收。
- 三组bank、四种分辨率、左右对齐共24组在途改值试验通过。另验证19通道、无效输入、下一转换、复位、取消及completion=off。

模式盘候选硬件为ADC2（控制器描述符2000D42C，外设base40012000，channel2）。原厂0803E2AC对四次采样求平均并分段，产生code0/1/2/3/6/5/4/10。挡位名字与整机效果必须由原厂运行另行验证；不能将ADC设备单测当作模式盘或相机已完成。
