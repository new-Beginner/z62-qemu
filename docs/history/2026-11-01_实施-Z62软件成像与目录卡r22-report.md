# Z6II r22：软件场景、镜头、JPEG与目录卡

本轮在冻结r21 QEMU旁接入显式C级软件相机，实现手动虚拟镜头、场景像素变化、JPEG拍摄、专用目录卡、回放缩放和删除。原版及候选加载分支均在实际QEMU会话中完成HTTP流程，输出JPEG由FFmpeg独立解码，并在正常关闭后重新打开卡核对。全量352项回归通过，耗时216.891秒。新增功能不执行尼康拍照编码算法，上方原厂画面和GPIO输入保持独立。原厂拍摄保存、NEF、视频、原厂AF、整机恢复及长期稳定性仍未完成；网页实点和布局验收被浏览器WebView附着失败阻塞。

## 范围、版本和资料

[scope](../../analysis/z62-camera-r22/scope.md)限定本地离线开发、普通文件和QEMU。没有连接相机、USB/PTP、物理盘或运行Tornado的设备访问脚本。Tornado旧的实机记录仅作为既有材料阅读，本轮没有重演。

QEMU为 `2026.10.30-r21`，SHA256 `0a772865868c4f666024533512d5ede2751255744caf56b594a41da6fc0ef90b`，本轮没有修改设备源码或重新编译QEMU。新宿主后端版本为 `2026.11.01-software-camera-r22`，Python3.12、NumPy2.4.1、Pillow12.2.0；FFmpeg来自本机已有PATH，仅用作独立JPEG解码。

同级 `AI/tornado-nkn/recovered` 的固件／交接／读取后端报告、脚本、反汇编及重放结果已阅读。三个执行载荷与本工程去CRC字节逐字节相同，完整哈希见[复用清单](../CAPABILITY-COVERAGE.md)。PC维修程序地址、固件VA和文件偏移保持区分；F040的BodyVr内部16位地址／长度以及RAM区域记录没有被误用为主ROM、传感器或镜头规格。新增光学模型没有伪装成Tornado或尼康算法。

## 实现和行为

`start-z6ii-software-camera.cmd` 在同一个QEMU会话中保留原厂控制台，另挂C级软件窗口。新 `/software/event` 和 `/software/status` 以QEMU已有客体时钟驱动软件相机；时钟读取失败拒绝操作，不回退宿主时间。

场景支持确定性测试图和本地图像，镜头有焦距、光圈、对焦位置／目标、行程、命令编号、延迟和移动状态。裁切、单平面模糊及曝光增益实际作用于像素；参数未校准，不具有真实镜头／尼康ISP精度。每张JPEG保存帧号、纳秒时间、clock_epoch、场景身份、镜头／曝光及编码前像素哈希，独立解码后可与拍摄时渲染结果比对。

目录卡只使用新建或带本项目标记的普通目录，拒绝其他目录、链接／重解析点、设备／网络路径和并发占用。清单为提交点，JPEG使用独占创建，正常重开保留编号和内容；回放缩放不修改原文件，删除后编号不回退。无卡、卡满、提交失败、外部修改／损坏与Python优化模式校验均有回归。它不是供固件挂载的SD/FAT卡，正常重开也不等于断电恢复或整机快照。

原模式盘测试的三层Request拦截已改为正常路径显式pre-stop回调；失败清理直接停止，报告保存last_state和探测器堆栈。两项针对性用例先失败后通过。旧KeyError记录保留，原版／候选新会话通过；由于旧输入工作线程异常没有重现，不能声称已修复其偶发底层原因。

## 复现命令

在本工程根目录运行，所有probe输出目录必须不存在：

```bat
python -X utf8 -B -m unittest discover -s tests -v
python -X utf8 -B -O -m unittest discover -s tests -p test_z62_software_camera.py -v
node --check tools/assets/z62-software-camera.js
python -X utf8 -B tools/probe_z62_software_console.py --output analysis/z62-camera-r22/software-local-check
python -X utf8 -B tools/probe_z62_software_console.py --firmware "Z6_2_0170 (1).bin" --output analysis/z62-camera-r22/software-candidate-local-check
python -X utf8 -B tools/verify_z62_mode_controls.py --baseline-console analysis/z62-camera-r22/mode-diagnostics-1 --candidate-console analysis/z62-camera-r22/mode-candidate-diagnostics-1
```

模式盘复核不带两个新路径时，仍引用历史原版失败目录并返回失败；这用于保留旧证据，不以覆盖旧文件改写成通过。
