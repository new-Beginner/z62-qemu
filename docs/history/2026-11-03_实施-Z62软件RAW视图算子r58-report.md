## 实现

[nikon-z62-video-source-pixels.h](../../qemu/z62-video-source/nikon-z62-video-source-pixels.h)的`z62_video_raw_view()`接收独立的输入／输出尺寸、stride、内存长度及显式origin，裁剪或补边RGGB packed12图像。它不是尼康传感器／ISP方程，也不决定实际视频ROI或光学中心。

| 合同 | 实际行为 |
|---|---|
| CFA相位 | 只接受偶数origin和偶数尺寸；奇数origin直接拒绝，不能静默取整改变颜色排列 |
| 横向补边 | 复制边缘完整2像素packed12单元，保持两个颜色位置，不把最后一个标量样本复制到另一颜色 |
| 纵向补边 | 根据输出行相位选择边缘同相位行，保留2×2 CFA排列 |
| 输入与输出几何 | 分别验证，不能将输入stride当作输出stride或反向解释原RAW |
| 容量／范围 | 最大4096×4096，stride最大65536；完整活跃范围、指针溢出与重叠检查在首次写入之前完成 |
| 非活跃存储 | 保留输出行padding和尾部，输入不改；函数不拥有DMA、源代数或内存映射 |

调用者必须先验证真实内存后备和来源生命周期，并显式选择origin。若需要奇数像素中心、重采样、缩放或另一CFA相位，需要独立转换，不能绕过这里的拒绝。
