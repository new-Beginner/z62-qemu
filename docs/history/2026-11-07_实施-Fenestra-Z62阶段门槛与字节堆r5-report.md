# Fenestra Z62 阶段门槛与字节堆 r5 进展报告

> 日期：2026-11-07。范围：用户本地 Nikon Z6II C1.70、自研 Z62-QEMU、固定 Fenestra 路线。flavor=null（普通固件分析）。
>
> **整体移植尚未完成。第一阶段尚未放行，第二阶段没有进入验收，真机阶段关闭。没有可安全刷入的候选包。有限模拟器测试不能证明真机绝对零风险，本报告不把“降低风险”偷换成用户要求的“一定不出问题”。**

## 1. 当前结果

本轮新增原厂上层字节堆的独立只读观察器、记录重放核验器和 17 项测试。恢复了缺失的固定 r69 运行目录及临时 Q: 别名，未更换 QEMU 版本。两个独立原厂运行每次各配对主侧 310 次、从侧 125 次分配，共 870 个入口/返回事件；块头、容量、邻居回链、保存寄存器、栈及 IRQ 状态检查通过。两次自然释放、失败分配、合并和精确地址复用样本均为 0。60 项 Fenestra 专项测试和 11 项候选镜像工具回归通过，无跳过；15 种变造记录被拒绝。

这些是 **原厂内存服务前置证据**，不是 Fenestra 在原厂固件内运行，也不是更新器接受修改镜像的证据。`PORT.json` 仍是 `experimental-loader-only`，卡载入、菜单、固件集成及刷机安全标志均为 false。

范围与授权：[scope.md](../../analysis/fenestra-z62-heap-r5/scope.md)。仅本地环回 GDB/QMP，`-nic none`；无控制器、参数、卡、Fenestra、相机、USB/PTP、物理磁盘或刷机操作。QEMU 模型预装原始镜像和 loader 初始化复位 PC，不等于调试器修改运行中指令/寄存器/RAM；后者全部未做。

## 3. 发现的问题、处理与复核结果

| 问题 | 原因/处理 | 修复和验证边界 |
|---|---|---|
| 上游现成模块不能直接给 Z62 使用 | 上游固定版本针对 AArch64；本地新增实验 ARM32/Thumb 格式及重定位后端，保留 Fenestra 路线 | r1 合成加载器证据本轮重新核验；完整平台服务/原厂移植没有完成 |
| 默认 memcpy 含 NEON、SHA 出现未对齐 LDR | r1 原故障分别为 UND 与 DFSR=1；使用整数 EABI 适配、soft-float、strict-align，不关闭客体异常检查 | 本轮重核验旧 r1 两份记录，各 58 检查通过；没有把它称为原厂固件集成 |
| 多核停止 CPU 与 `qC` 不一致，传统单步恢复其他 CPU | r4 已定位；读取停止包 `thread:`，新工具复用 `vCont;s:<CPU>` 隔离单步 | r5 两次实际记录中原指令单步/CPU/断点生命周期重新核验；CPU 仍不是 RTOS 任务 ID |
| r69 原运行目录、Q: 别名缺失 | 找到两份 EXE 哈希与固定 r69 完全一致、9 份程序/DLL 逐文件一致的本地副本；拒绝覆盖后恢复运行目录，临时建立 Q: | 版本 10.2.4、Z62 机型检查和本轮原厂运行通过；来源/逐文件哈希见环境恢复记录；不声称找回了历史构建树 |
| 错把下层块数、上层字节数和 flags 混用会破坏内存 | 静态原字节确认：上层核心 r0 字节数，至少16并8对齐；r1 是描述符。下层 r0 是 2 KiB 块数；释放封装 r1 才是 flags | 本轮动态核对分配容量/块头/回链；观察到请求8字节被按最小16字节处理。不能直接把两层入口当 C malloc/free |
| 上层释放返回值不能套“0=成功” | 原释放封装尾跳 IRQ 恢复，r0 是 helper 原返回，不是已证明的状态码 | 新解析器保留原值，合成测试覆盖非零返回、双向合并及复用；**原厂自然释放仍0，未宣称修复或验收释放 ABI** |
| 新诊断字段插入误覆盖文件保存语句 | 编辑回显发现后恢复保存语句，在启动 QEMU 前修正 | AST、13项合成及边界测试、4项重放测试和最终60项专项测试通过；没有将语法错误版本作为成功运行证据 |
| 观察结束没有新断点 | 两个长窗口在记录870事件后，各一次15秒接收无新断点 | 如实以有界接收结束；不是原厂启动完成、无 Error、卡载入或正常关机的判据。不能靠重复等待/注入调用补齐释放样本 |

## 4. r5 原字节与动态结果

### 静态等价导入锚点 E-imports

目标为无 PE/ELF 导入表的原始 ARM/Thumb 固件成员；等价锚点是原始 BL/尾跳转、初始化描述符与 IRQ helper 字节，保存在原静态合同和新观察合同中。使用本机 Capstone；没有安装/启动 IDA 服务或计划任务。技能的 `tool-index.md` 与 `field-journal/precedent-reverse.md` 缺失，已记录，不假装读取成功。

| 接口 | master | slave | 限定解释 |
|---|---|---|---|
| 字节分配核心（ARM） | `0x10108678` | `0x1003A04C` | r0 字节数，r1 描述符指针 |
| 释放封装（ARM） | `0x10108908` | `0x1003A2DC` | r0 用户指针，r1 flags，尾跳 IRQ 恢复 |
| flags 分配封装 | `0x10108870` | `0x1003A244` | 选择描述符后尾跳核心 |
| IRQ 保存/恢复 | `0x10109630` / `0x10109640` | `0x1003B004` / `0x1003B014` | 只确认原指令，不外推完整同步/调度合同 |

分配返回用户地址前8字节为被观察块头：第一字为下一块头地址，第二字含前块地址及低位标志。新观察器只读目标及两级有限邻居，最多24个合法范围内头部；不能用该范围证明真实 DRAM 容量或可供插件使用的自由空间。分配检查 used 位、原8字节对齐、请求容量/未拆分余量、相邻回链、r4..r11/SP和模式/IRQ/FIQ恢复；保存描述符和下层池状态，不声称完整自由链表已验证。

| 短窗 run-1-diagnostic | 57972 | 600 | 213 / 87 | 0 / 0 / 0 | 3.281秒 | 真实退出0，quit有应答 |
| 长窗 run-2-long | 42208 | 870 | 310 / 125 | 0 / 0 / 0 | 19.532秒 | 真实退出0，quit应答前连接重置 |
