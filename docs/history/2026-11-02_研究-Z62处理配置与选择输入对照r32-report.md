# Z62 RAW边界／连续统计配置与持续选择输入对照 r32

报告日期：2026-11-02。实现标识仍为`2026.11.01-selector-processing-profile-r32`；这是观察程序版本，不是新QEMU内核发布。

此前r28—r31虽然使用已有r21内核，实际命令没有启用r17 RAW边界和r18连续统计模型。本阶段新增显式配置观察程序，进行了同内核、同输入、同卡镜像的开启／关闭对照。两个模型开启后确实产出数据，初始化回调在模型内更早执行；两组切换后均未恢复OSD。这不能作为默认入口升级或完整相机验收。

## 范围与实现层级

授权／离线边界见[scope](../../analysis/z62-selector-r32/scope.md)。原厂调用与队列为A；RAW边界和区域统计是既有B／C功能模型；新程序是只读实验控制与采样。没有新增原厂ISP算法、AF或照片／视频模式身份。

`tools/trace_z62_selector_processing.py`显式组合已有配置函数，仅增加：

```text
-global nikon-z72-boot-config.z62-raw-boundary=on
-global nikon-z72-input-config.functional-continuous-stats=on
```

`--legacy-processing`保留旧配置。没有写软件就绪字、调用回调或伪造完成事件。
