## 如何解读这张图

它描述的是基础仿真/研究能力，本身也写明未组成完整相机、未证明完整拍照录像落盘。当前公开 main 不能给“TPJ/NDS32、VR/RX测试机、有限虚拟镜头、NVMe”等新增表述背书。可能是另一个仓库、尚未推送的本地版本，或表格超出了已公开实现；缺少对应源码位置，不能判断是哪一种。

对Z62可参考的具体进展是完整RAW分片/对端缓冲所有权、原厂曝光设置到机身快门的路径、数据成功后才通知及LCD/结果观察。地址、几何、IRQ与镜头/存储合同必须按Z62重新验证。

图片和当前main均不证明前述自定义原厂界面、AF-C合焦变绿、自动竖屏或机内8-bit N-Log已实现，更不能证明修改固件刷入真机安全。
