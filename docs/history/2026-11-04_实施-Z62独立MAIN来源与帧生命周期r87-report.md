# Z62 r87：独立 MAIN 来源与帧生命周期

2026-11-04，层级C，设备集成仍D。范围见[scope](../../analysis/z62-main-source-r87/scope.md)。新增独立MAIN生产者、帧封装和C缓存读占用，把已有场景实际送进r86两级像素核心；模型中的背压、取消、停止和复位已有原生验证。原厂run／commit、ring-bank、DMA／IRQ以及LUT下游逆变换尚未接入；r69／r75运行组合不变。

## 实现和复用

- `tools/z62_main_frame.py`：明确的MAIN／linear16／RGGB帧，96字节头、独立stride、30 Hz帧号、epoch、publication、时间、黑白电平和两种CRC。旧`Z62S`接口保持冻结。
- `qemu/z62-capturework/nikon-z62-main-source.h`：纯C11解析、预检、单缓存和读占用。无MMIO／timer／DMA／IRQ；占用时背压；旧serial、重复释放及序列回绕拒绝。取消后的旧指针不再有效，要求序列化调用。
- `tests/native/z62_main_source_probe.c`及Python专项：实际GCC编译和普通文件输入，再调用未改动的r86像素核心。
- `tools/probe_z62_main_source.py`：复用原有Scene的移动测试图与r86几何／LUT，保存输入、输出、8份原始源码和SHA；NumPy独立两次实化采样、RAW12解码全样本比较。
- `tools/check_z62_regression.py`：完整unittest发现、stdout／stderr日志及失败名称，输出都在工作目录。

C生产者对sRGB8场景做近似线性化，并非尼康真实传感器标定或内部PDAF。完整合同见[MAIN-CONTRACT](../../qemu/z62-capturework/MAIN-CONTRACT.md)。参考仍为nightglasses的CaptureWork划分与已有Z62工程；本轮未运行或扩大NKN维修功能。
