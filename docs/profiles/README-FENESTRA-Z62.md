# Fenestra Z62 ARM32 加载器试验 0.1.0-dev.1

**仅离线研究，不可刷机，也不可把生成的 `.wlm` 放入真机。完整 Fenestra 移植尚未完成。**

当前成果是把 Fenestra 的模块检查／复制／重定位层移植到 ARM32，保留原 v1 `FxModuleServices` 日志入口。它在现有自研 r69 Z62-QEMU 的合成 ARM 程序中运行，不加载或修改 Nikon 固件。当前 SDK 服务管理、原厂启动／关机、卡文件与菜单适配仍缺。

## 实际验证

- 5项 Python 格式单测、11项现有候选加载回归通过。
- 29种格式夹具在两个镜像地址各检查一次；32位探针58次检查通过，含2次真实 Thumb 入口／日志回调／返回；其余56次为负例拒绝，拒绝后镜像／保护区不变。
- 默认 AArch64 格式分支与未修改上游 C 加载器，各58次主机格式检查结果一致；**不表示 AArch64 相机运行回归已通过**。
- 最终 QEMU 窗口独立复跑两次，均正常退出；使用既有 r69 EXE，SHA256 `37603d1f8c55f819c0e1d3808e670d2de562b954152f2d8b847d1068359296f9`，未重编或修改它。
- 最终构建为 `.build/fenestra-z62-0.1.0-dev.1-r7`。运行证据在 `analysis/fenestra-z62-r1/run-4.json` 与 `run-5-repeat.json`；此前失败记录保留。

## 源码与合同

`fenestra/upstream` 是 Fenestra `b199dcdfbb0ef536c6269ae5a9d97c376d488b8b` 的独立 Git 工作副本，许可证／NOTICE 保留。只修改 `include/fenestra_module.h` 和 `src/module.c`；没有改写上游 `main` 或现有 Z62 子模块。后续发布前仍需独立处理源码分发清单、许可证及仓库依赖，当前未发布／提交。

新增试验文件在 `fenestra/z62`：

- `pack.py`：合成模块夹具，不是通用 ELF 打包器或固件补丁器。
- `module.S`：独立编译的 Thumb 日志模块，入口偏移2，含字符串和函数指针重定位。
- `probe.c`、`start.S`：无固件执行、负例／内存保护区检查及首异常记录。
- `aeabi.c`：调用现有 Fenestra 内存函数的整数 ARM EABI 适配器。
- `build_probe.py`、`run_probe.py`：新目录构建、源码／产物／QEMU 身份检查和自有进程清理。
- `PORT.json`：阶段／版本与未验收字段；它是状态说明，不是安全认证。

ARM32 使用本地实验 ISA／重定位值 `0x62000001`，32位重定位与2字节入口对齐；旧 AArch64 默认 ISA=1、重定位 kind=1、8字节宽度不变。不是把旧 AArch64 插件改标识就能运行。

## 重跑

要求当前完整本地研究环境：普通源码克隆没有 QEMU、固件、编译器和构建缓存。需要已验证指向本工程的 ASCII `Q:` 别名、原始 C1.70 master、固定上游副本和本工程 GCC。工具不访问相机。

本轮固定 Zig 0.13.0／Clang 18.1.6，安装在会话 PI scratch，未修改系统 PATH；scratch 删除后需在工程内重新准备同版本工具，显式提供 `--zig`。它不等于上游 AArch64 r3 的复现工具链。下列 Git Bash 命令与本轮实际调用对应；输出名需选择尚不存在的目录／文件：

```bash
export TEMP="$PI_SCRATCH_DIR" TMP="$PI_SCRATCH_DIR" TMPDIR="$PI_SCRATCH_DIR"
export PYTHONDONTWRITEBYTECODE=1
python -X utf8 -B -m unittest discover -s tests -p test_fenestra_z62_pack.py -v
python -X utf8 -B -m unittest discover -s tests -p test_z62_candidate.py -v
python -X utf8 -B fenestra/z62/build_probe.py \
  --output .build/fenestra-z62-0.1.0-dev.1-recheck \
  --zig "$PI_SCRATCH_DIR/ziglang-0.13.0/ziglang/zig.exe"
python -X utf8 -B fenestra/z62/run_probe.py \
  --build .build/fenestra-z62-0.1.0-dev.1-recheck \
  --output analysis/fenestra-z62-r1/recheck.json
```

如发生异常，保留对应 JSON／QEMU log，不覆盖旧结果或删掉身份检查。该运行器的 `completed=true` 仅表示合成探针检查及清理完成；`firmware_integrated`、`flash_safety_verified` 仍为 false。
