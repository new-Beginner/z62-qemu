Issues and specs live in GitHub Issues on `new-Beginner/z62-qemu`, driven with the `gh` CLI. See `docs/agents/issue-tracker.md`.

Canonical five-role vocabulary, each label string equal to its role name: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.
