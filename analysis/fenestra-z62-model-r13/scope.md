# r13：离线、可追溯的 Z62 模型新重建

本轮承接用户原 Fenestra/Z6II C1.70 移植目标，仅推进第一阶段的模型来源缺口。不生成候选固件或可刷包，不连接相机、USB/PTP、物理卡/磁盘，不刷机。

- 使用已缓存 QEMU 10.2.4，SHA256 `821b545b92f165e57dddccac5077d76d4d436a226595b8813ad59306bbfd0746`，参考仓库固定 `4f4389944fc339d107f22f5f7ca3f90cc34b78de`。
- 在全新 `.build/fenestra-z62-model-r13-*` 目录重新生成并构建；旧目录、r1～r12绑定源码/记录、原固件、旧r69 runtime保持不变。不得绕过旧构建器缺失manifest或immutable guard续建。
- 新入口复用现存适配器的纯render/摘要检查；r4可直接用于新.build源，r5无render，独立复制其转换体并检验与原体一致；新入口自身保护新目录。不得改冻结摘要适配错误层序。
- 各层输入/输出/适配器/header摘要、完整源码清单、命令、日志、当前工具链和输出身份均独立保存。离线编译禁下载；临时文件仅实际PI scratch/工程内部。
- 新产物不是旧r69二进制或精确构建来源的证明；源码重建也不等于物理协议正确、默认completion已关闭、完整Fenestra集成或更新流程验收。
- 如启动新模型，仅原C1.70、`-nic none`、127.0.0.1调试端口；禁止改客体指令/返回值/RAM/PC，禁止注入调用/事件，只有既有loader复位初始化允许。
- 第一阶段Q1～Q6完整方案未全通过，第二阶段U1～U6不进入验收，真机门槛保持关闭。有限模拟测试不能证明真机绝对零风险。
