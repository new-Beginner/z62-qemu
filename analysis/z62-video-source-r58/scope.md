# r58 显式软件RAW视图算子

只实现有边界的C级packed12裁剪／补边数值函数，为后续独立软件ISP路径提供原语。输入与输出几何／stride独立，调用者显式选择origin；偶数origin保持RGGB相位，越界只复制相同颜色的2像素单元／同行相位。不自动推断尼康ROI、缩放、光学中心或真实ISP。

1514×1006／row2272→1516×854／row2288、origin(0,76)仅作为明确指定的软件数值夹具，不能称为已恢复的视频转换。当前不接入QEMU、不改r53、原固件、IRQ、ready、队列或r49验收门槛。原厂三阶段来源证据继续由独立r57记录。network_profile=offline。
