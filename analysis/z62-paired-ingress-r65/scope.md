# r65 软件paired输入实验范围

auth：延续完整目标中的本地开发／仿真授权及允许显式软件ISP的要求。in_scope：独立、默认关闭的C级paired帧源、固定原厂请求的配置、统一现有scene mailbox、RAW缓冲实际DMA和既有软件ISP输出、边界／背压／停止／复位验证。network_profile：本阶段只用本地工具与已有源码，不访问相机、USB、WPD或物理盘，不发布GitHub。

基线为r64b；已有adapter、头文件、内核与证据冻结。新模型仅允许原RAW stream已停止时接管paired请求中给出的四个缓冲地址；不写RAW启动锁存，不产生RAW完成／统计结果，不改ARM、ready、队列、原厂等待或超时。实际输出完成仍由原有软件ISP在数值计算与DMA成功后负责。

此模型有意使用现有1514×1006 packed12 C级场景源；视频沿用显式origin的C级格式桥，不声称传感器、ISP或30fps时序等价于物理硬件。原始帧编号／时间戳、投递计数和QEMU DMA时间分别记录。原生夹具通过不等于原厂固件恢复；需另做不附加宿主调试器的完整原厂场景验收。
