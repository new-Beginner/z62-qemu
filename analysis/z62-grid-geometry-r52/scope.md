# r52 变尺寸 grid 与保留输入实验

基于 r50/r51 的原厂快照：实际 bank0 端口为 60×34、RGB row128、packed12 row96，参数 Y 上界由39变33；旧照片为60×40。RAW格式仍1514×1006，RAW事务继续增长，而统计和六槽来源停在767。不能把此问题简化成RAW停止或直接改成846行。

本阶段新增独立默认关闭的几何支持，以及**单独默认关闭的C级保留输入策略**。后者只允许新的显式命令3，对此前由真实统计DMA成功供给、仍有界可读的RGB执行新的数值作业；它不宣称发生新采集，不增加RAW/统计来源计数。只有实际四输出写回成功才报告原有结果及命令完成，ACK/读取不能重放已完成作业。停止撤销未完成请求，复位清除全部请求身份，私有来源缺失仍等待。

保留输入的物理缓存生命周期尚未恢复；这是用户已允许的软件模型路线下的显式实验，不把它称为尼康硬件等价行为。几何支持和保留策略分别开关，保留同内核对照。保留r48及所有旧证据，不修改原厂ARM/ready/队列/计数/超时，不在完整恢复和回归验收前升级默认入口。

当前只推进bank0图像算子与请求生命周期。paired的1516×854逻辑布局、MAIN普通RAM、WORK输出和预览仍是独立后续工作；不能以本模块通过宣布视频、AF或整机完成。
