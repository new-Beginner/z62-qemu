# r16工作范围

- auth：用户明确要求读取现有工作区，继续实现供其离线测试固件的Z6II QEMU。
- in_scope：原厂C1.70静态分析、隔离QEMU动态观察、外部GPIO输入合同、宿主控制台、测试及文档。
- out_of_scope：物理相机、USB/PTP、物理磁盘、真实刷机；修改原厂指令、CPU返回值、软件就绪/错误字段；伪造照片或完成通知。
- network_profile：仅本机QMP、GDB与HTTP；未连接相机或远程设备。
- 输入：固定哈希的master/slave/controller，冻结r13内核；实验NOR23不是真实标定。
- 模拟边界：PG0高表示未安装镜头，镜头通信协议未实现；快照虚拟卡不用于持久照片验收。
- 完成边界：此阶段采集许可与输入验收不等于整机、拍照保存或刷机安全验收。完整目标保持active。
