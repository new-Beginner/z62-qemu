# r32 离线配置对照范围

授权依据为当前目标文件和用户关于Z62／Z72参考仓库的请求。工作区仅运行原包、普通虚拟卡文件及已有QEMU设备模型。

- 比较同一冻结r21内核下启用／关闭既有RAW边界和连续统计模型的差异。
- 仅用GPIO电平驱动原控制器；通过GDB和QMP只读采样原厂处理，不写就绪字、不调用原厂函数、不注入成功事件。
- 专用4GiB普通文件卡启用snapshot；禁止访问物理相机、USB/PTP、物理盘、真实NOR或许可证／计数。
- 观察计数、初始化队列及扩展器pin0持续选择输入；不预设该输入的实体名称。
- 不验证原厂全分辨率拍摄／视频、AF、完整相机或刷写安全；不修改默认入口和冻结设备。
