# r63b QMP超时的宿主线程观察

仅本任务QEMU的只读宿主诊断。复用r62固定EXE与相同C视频／停止选项，不改变客体算法、ready、队列、等待／超时或完成。只在既有QMP观察超时后抓取一次主机GDB14.2线程栈，原超时恢复上限不改，不重发控制。

附加前以保留Popen对象、原PID、实际执行路径、EXE SHA重复核对所属，不枚举并选择其他用户进程。符号／运行库使用manifest逐文件校验的ASCII临时副本，原构建／固件不改。GDB禁自动加载脚本、关闭debuginfod网络，25秒有界，显式detach；只记录自身日志。宿主附加会暂停并扰动进程，因此发生抓取的窗口不作为功能恢复验收。

native-1机械attach／detach通过，但中文DLL路径导致库XML解析失败、栈缺符号，不能用于归因；native-2经ASCII运行库后得到QEMU／MTTCG线程符号，detach后QMP继续响应。新诊断窗口必须记录实际是否附加以及观察／功能边界，不把故障消失或抓取成功当作模式恢复。
