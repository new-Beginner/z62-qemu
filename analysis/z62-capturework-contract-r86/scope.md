# r86 范围与授权

日期：2026-11-04。范围为工作区中 Z6II C1.70／r69 的只读仿真观察、独立 C 像素运算及合成输入验证；后续按用户明确要求整理公开源码和文档、提交并推送到既有 new-Beginner/z62-qemu。

没有连接相机、USB/WPD 或宿主物理盘；没有刷写固件、修改 AF、改原厂等待／返回／队列或补 ready。独立核心没有 QEMU DMA/IRQ，MAIN 是显式合成数据，寄存器读回不等于 commit 来源。r69 绑定源码、EXE 和历史回执保留。

完整固件／原始 RAM／完整轨迹、虚拟卡、工具链及 NKN 原件不公开。公开报告只给出已核验摘要、原件哈希和复现源码。所有新增产物位于 D 盘工作目录；Q: 仅为其 ASCII SUBST 别名。
