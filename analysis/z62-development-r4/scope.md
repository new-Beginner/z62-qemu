# Z62 r4 实施范围

用户授权继续实现可推进的 Z6II QEMU 功能，参考 Z6/Z72，先交付可用实现再汇总缺口。

- 目标：独立原生 Windows r4、默认关闭的描述符有界合成 RAW、虚拟 SD 快照/持久化、只读健康观测、原固件菜单验证。
- 不访问物理相机/USB/物理卡，不发送 PTP，不刷机，不改变原固件字节、PC/返回值/错误列表，不发布固件/参数/密钥。
- 保留旧 runtime、donor、现有用户改动；无提交/推送。
- 默认 baseline，RAW off；实验参数及 init-mode 明确标注，非真实 NOR/校准。
- 单元/qtest、SDHCI、原固件 UI、菜单循环、取景、拍照保存分别验收。
- 成功循环必须完整空状态列表，真实退出/重开/导航；未知失败关闭。
- 动态上层等待追踪位于 ../z62-upper-waits/；断点时序不能充当正常性能验收。
- 旧 8662 展示在本轮开始前已不存在；本轮未恢复或关闭它。最终测试实例正常退出，无继续运行的演示。
