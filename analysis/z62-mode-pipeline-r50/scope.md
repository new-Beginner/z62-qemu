# r50 新模式数据合同取证范围

日期：2026-11-03。用户恢复完整 Z62 目标并授权结合刚完成的 nightglasses Z7II 参考继续推进。本阶段从 r49 已证明的切换失败出发，补齐 `1D09` 模式的 RAW、统计、两组 ISP 端口/表和引用参数，不重复将旧模式成功当作恢复成功。

- 沿用冻结 r48 QEMU、原始 C1.70 三载荷、显式非出厂 group23 和 snapshot 卡。保持 r48/r49 文件及默认启动入口。
- 只施加既有持续输入 pin0 的低→高外部电平；物理照片/视频拨杆身份仍未验证。
- 调试器只读原指令、寄存器和数据。内存读失败保持未知，不返回零替代；不写原厂 ready、软件计数、队列、回调或成功返回，不补完成 IRQ。
- 捕获实际 RAW 编程字段及 DMA 目标，不能根据命令组高度 34/846 推定 RAW 几何。统计和 grid 输出分别保留其自身描述符、行跨度及映射表。
- 快照明确非原子；RAM 内容和已编程地址不自动证明新代数据已成功产生。参数尾部可能包含软件记账，不把它作为硬件完成依据。
- 本次新增工具由现有 r49/baseline 执行框架承载，不建立第二套固件执行器。所有新输出使用独占创建，保留旧失败和固定输入。
- 已重新读取 NKN README-source、acquisition/r1 交接及最新 service/r14：它们不是完整机身 ROM，也没有提供新模式 ISP 或完整 Z 触点规范。没有运行其中设备采集/维修脚本。
- 取得合同后再按证据实现独立软件 ISP 扩展。当前阶段不能提前验收模式恢复、原厂拍照/存卡、AF 或整机；完整目标保持 active。

上一目标实施回合 r49 是实质进展：原厂新模式失败和新命令改变了下一动作。刚完成的 Z7II 拉取/构建提供了可复用源码与原生验证，本阶段将其方法用于 Z62 自身数据合同。
