# r18阶段范围

- auth：用户的完整Z6II离线固件测试QEMU目标保持不变；本阶段实现其连续统计数据部分。
- in_scope：固定原模块只读分析/CPU读观察点、独立五路统计设备、原生/原厂回归、证据与文档。
- out_of_scope：物理相机、USB/PTP、物理盘、修改原固件或软件状态、虚构照片或未执行的数据完成。
- network_profile：本机QMP/GDB/HTTP；无远程相机连接。
- 数值近似：基于实际RAW场景的区域和/均值，不代表未知的尼康裁剪/校准/阈值算法。
- 所有失败记录保留；完整目标仍active，部分数据/读取验证不等于拍照、更新或刷机安全验证。
