# 范围与授权

- auth：用户拥有 Z6II，提供本地 Z6II/Z7II 固件并授权离线分析、网络检索和独立开发。
- in_scope：原始包身份/CRC、固定开源参考、Windows 原生 QEMU 构建、原固件菜单画面与正常按键输入、本地证据与回归。
- network_profile：公开 GitHub/网页资料；控制台和调试接口仅 127.0.0.1。
- out_of_scope：实机连接、PTP 操作、刷机、拆机、上传固件、签名能力声明、完整传感器/照片/录像验收。
- integrity：不改客体指令、应用索引、分支或返回值制造启动；合成参数和设备合同明确标注。
- privacy：固件、参数组、密钥和临时运行副本不入 Git/公开包。菜单截图仅保存在忽略的 artifacts 目录。
- 本次为普通固件逆向与复现，报告 flavor=null；无恶意软件/攻击活动结论。
