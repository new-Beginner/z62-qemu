# r62 显式RAW停止请求实验

基于r61原厂调用／掩码证据及`raw-stop-red.json`的实际native失败，新层只在显式`z62-raw-stop-control=on`时处理`2006800C bit200`，停止该RAW来源的后续产帧，需新的20068008启动。默认关闭，冻结r60／r59b保持。

不增加完成／IRQ，不强开统计，不改原厂ARM、AF、ready、队列、等待或超时；不声称真实硅片协议等价。VMState52/min52仅增加配置bool。先验证真实DMA停止／内存保持／显式重启和旧回归，再决定原厂窗口。构建、原生和模式恢复是独立验收门槛，不能相互替代。

仅本地仿真和专用虚拟卡snapshot，无设备访问或发布。构建工作区`.build/z62-raw-stop-control-2026.11.03-r62`独立创建，绑定adapter构建期间不改。
