# r48 命令组 0 软件 ISP 的范围

- auth: granted。用户已恢复完整模拟器目标，并指定 ISP 当前使用软件模拟。
- in_scope: 本地 C 数值函数、独立 QEMU 设备构建、无固件原生验证、固定原始 C1.70 的有界运行与只读 GDB 观察。
- network_profile: offline。未访问相机、USB/PTP、物理盘或远程服务。
- out_of_scope: 实机操作、刷写、许可证与计数修改、AF 算法设计或优化。
- 层级：A 原厂 ARM 执行；B 有证据的传输/IRQ 模型；C 三通道均值和 packed12 软件运算；任意 11 节点数学与完整相机仍未实现。
- 数据：仅既有连续统计设备已实际 DMA 写出的 RGB 六槽；新内部通知仅记录模型内数据来源，不冒充真实卡口或实机 GPIO。
- 完成：配置、输入与输出范围及数值通过检查，四份输出实际写回后才锁存结果与命令状态，沿既有 IRQ102 路由。
- 禁止：宿主写原厂 ready、队列、跳过计数、成功返回或软件完成事件；不缩短原厂超时。
- 原厂输入：固定 master/slave/controller；group23 为既有非出厂标定夹具；虚拟卡为普通文件 snapshot。
- 默认关闭新设备，冻结 r21/r24/r47/r47b、默认入口及 13 项 r27 交互源保留。
- 证据目录独占创建；父内核负对照、首次原生联动配置失败和旧 C 实验均保留。
- 运行以 12 秒客体时间为预算；350 停顿，末个命令完成尚未消费，不作无限期稳定或模式恢复结论。
- 控制台一段输出遭工具截断，标为 partial；完整结构化 trace、原始输入/输出快照及哈希单独保存。
- protocol-reverse/docs-generator 的补充 field-journal/tool-index/ops 文件本地缺失，未安装新工具；采用其已读方法和本项目已有观察工具执行离线任务。
