# r64 原厂DMA／formatter／commit写入时序

延续完整目标／任务一优先，只做本地仿真和公开已有源码分析。固定r62 EXE及r63b ASCII运行副本，不更改C模型、原始ARM／AF、ready、队列、完成或原厂等待／超时，不接入相机或发布。

使用已原生验证的memory_region_ops_write日志，记录absolute地址、CPU、值、大小和区域。事件在设备回调之前，必须称为写入尝试；native夹具可用寄存器读回交叉验证，原厂所有事件不能默认接受。ISO前缀是宿主时间，不能当guest虚拟纳秒；相同时间／同值写入保留。

源日志全部保留，主分析选取20060000–2006BFFF、20100000–2010FFFF、20380000–20380FFF；其他区域保留计数及原始文本。控制族与r60诊断环按角色／地址／值／CPU顺序核对，不跳过不匹配找方便匹配；最后环之后的日志单列，不填成空或声称cleanup全观察。

日志默认256MiB预算、输入／输出卷各需2GiB空闲。超预算会终止此观察并如实标不完整，不改变相机控制继续造成功。宿主GDB策略沿r63b，若实际附加则不能作功能验收。trace开销也会扰动宿主时序，不代表物理性能。
