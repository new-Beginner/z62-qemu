# Z62 全按与存卡研究范围

- auth：延续用户实现完整离线Z6II QEMU的目标。
- in_scope：原版C1.70在冻结r9内核运行；控制器PG1/PG13外部输入；独占新建4 GiB虚拟FAT32卡；客体文件写入观察；只读GDB、反编译和目录检查。
- out_of_scope：物理相机、USB/PTP、物理盘、原固件修改、软件状态或返回值强写、以宿主生成照片冒充原固件保存。
- network_profile：QMP/GDB/qtest仅回环地址，无相机网络连接。
- r11是研究批次名称；没有编译r11内核，也没有替换当前r9/r10b统一入口。
- 长时无断点运行与带执行断点的路线追踪分别记录，不能相互替代时序验收。
