# r17范围

- auth：用户要求持续实现可供其离线测试固件的完整Z6II QEMU；沿用工作计划的隔离约束。
- in_scope：固定C1.70原模块的只读运行追踪、原生RAW边界外设、独立新内核、回归与文档。
- out_of_scope：物理相机/USB/PTP、物理盘、修改原厂指令/软件字段/返回值、伪造统计或照片完成。
- network_profile：仅本机QMP/GDB/HTTP。
- 事件0单次外部脉冲是有界IRQ路线诊断，必须记录RAW读回与诊断身份，不加入正常入口。
- 新原生模型仅在实际成功的RAW事务后报告输入边界；同帧相位属于功能假设，未证明硅片时序。
- 保留旧r13+r16默认入口，只有更广整机验收通过后才能升级；完整目标仍active。
