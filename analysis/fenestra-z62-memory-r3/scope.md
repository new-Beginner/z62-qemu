# Fenestra Z62 RTOS内存初始化 r3 范围

仅继续已授权的Fenestra移植离线前置研究，原输入Z6II C1.70、自研固定r69 QEMU。

本轮恢复原厂堆边界写入者、RAM页表切换、内存池元数据与空链表初始化；只观察原厂自然执行，不注入函数调用，不改运行中寄存器、RAM、指令、返回值或就绪状态。原始镜像由模型预装，QEMU loader初始化复位PC；不是相机更早加载器证据。Z7II研究只作结构线索，全部地址回到Z62原字节核实。

不带参数、控制器、卡或插件，不执行USB/PTP/物理相机、更新、NOR写入。GDB/QMP仅本机环回，断点扰动时序；QMP quit只证明自有QEMU正常结束。

堆初始化成功不证明分配/释放ABI、并发、内存所有权生命周期、可执行内存/cache发布、Fenestra集成或刷机安全。对应字段保持false；可刷包和真机门槛继续关闭。
