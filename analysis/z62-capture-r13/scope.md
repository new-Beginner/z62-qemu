# Z62独立采集接点研究范围

- auth：用户明确要求在现有工作区实现可测试其固件的Z6II QEMU，并参考其他机型。
- in_scope：本地C1.70模块静态分析、隔离QEMU、只读执行断点、外部接点输入、普通文件虚拟卡、独立新设备内核与复核工具。
- network_profile：本轮使用本地回环QMP/qtest/GDB；不连接相机、物理存储或USB/PTP设备。
- 保留原固件、冻结r9及所有失败记录；新设备默认关闭。没有改固件指令、CPU返回值、软件就绪标志、错误列表或伪造照片。
- 电气模型：资源58/59及其GPIO/IRQ来自本机原固件运行时绑定。将一个机身接点同时送到MCU按键路径与采集GPIO属于功能性板级连接模型，精确传播延迟、去抖及实际电路未测量。
- 完整成像、照片保存回放、更新/NOR和真机刷写安全不在已有通过结论内；整机目标仍在进行。
